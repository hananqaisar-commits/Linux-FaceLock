Install

Get started in seconds.

Three methods. Same result. Pick what fits your workflow.

Quick install with wget

# Download the installer
wget https://github.com/hananqaisar-commits/NovaUnlock/releases/latest/download/nova_unlock_installer_v4.6

# Make executable and run
chmod +x nova_unlock_installer_v4.6
sudo ./nova_unlock_installer_v4.6

One-line install with curl

# Download with curl
curl -L -o nova_installer \
  https://github.com/hananqaisar-commits/NovaUnlock/releases/latest/download/nova_unlock_installer_v4.6

# Install
chmod +x nova_installer && sudo ./nova_installer

Clone from GitHub

# Clone the repository
git clone https://github.com/hananqaisar-commits/NovaUnlock.git
cd NovaUnlock

# Run the installer
sudo ./releases/nova_unlock_installer_v4.6
